# ORA

ORA is a cross-platform application built with Expo and React Native.

## Development

Install dependencies and start the development server:

```bash
npm install
npm start
```

Application routes live in `src/app`. Shared application infrastructure is organized under `src/components`, `src/lib`, `src/screens`, and `src/theme`.

## Checks

```bash
npm run typecheck
npm run lint
```
